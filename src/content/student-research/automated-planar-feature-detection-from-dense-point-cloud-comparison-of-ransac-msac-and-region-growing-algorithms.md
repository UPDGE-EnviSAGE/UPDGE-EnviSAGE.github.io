GeoSLAM Zeb REVO is the hand-held laser scanner used to generate the dense point cloud of the Melchor Hall building covering only the Ist and 2nd floors of the Geodetic Engineering wing. Random Sample Consensus (RANSAC). M-estimator Sample Consensus (MSAC), and Region Growing are planar feature detection algorithms and these were implemented on different programming languages to utilize the availability of existing libraries and functions. These are optimized by determining the best values of the parameters used in each alcorthm. mne gencraced planes • or each algorthms were compared through visual inspection, and assessment of percent coverage and misclassification. The generated planar features from the RANSAC algorithm provided planar features that covers the major planar features in the early runs but misclassifications were prominent. While for MSAC algorithm, the generated planar features were consistent on detecting and covering the majority of the major planar features but there were minor misclassifications on some generated planar features on the later runs. Lastly, Region Growing generated planar features that formed a significant number of thinly dispersed planes covering a single plane multiple times but misclassifications were not prominent. With these, the MSAC algorithm's performance showed the best results and was implemented on the denser and larger point cloud. Results of this study suggested the great potential of using an automatic approach on planar feature detection.
