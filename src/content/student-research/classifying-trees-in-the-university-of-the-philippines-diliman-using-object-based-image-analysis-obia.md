abstract: |-
  The study focuses on developing a ruleset-based approach to identify common trees at object-based level from LiDAR and unmanned aerial imagery (UAS) data. Using seven (7) data layers, particularly RGB (Red, Green, Blue), HSV (Hue, Saturation, Value), and nDSM (normalized DSM), the area is classified into objects with homogenous features through multiresolution segmentation. Then, the features of the data layers which includes mean, standard deviation, and texture statistics after Haralick using a classifying algorithm like SVM (Support Vector Machine) are used to classify the eight (8) most common tree species. Segmentation parameters like scale, compactness, and shape were evaluated in different values on its accuracy in classifying each tree species. The conventional error matrix approach is used to evaluate the results. Based on the results, tree species with larger tree crowns require higher value of scale, tree species with denser crowns require higher value of compactness, and those with well-distributed tree crowns needs higher value of shape. In an urban area with high spatial heterogeneity and species diversity of trees, an object-based approach is chosen rather than pixel-based to map trees. This addresses the problem of mixed pixels and within-object heterogeneity that are common in pixel-based approach. The study indicates LiDAR data in conjunction with unmanned aerial imagery (UAS) are not only capable of approximating tree crowns and metrics, but also identifying their classes using the proposed methodology.
