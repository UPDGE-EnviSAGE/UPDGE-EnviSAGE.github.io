abstract: |-
  This research aims to map existing benthic habitats in Santiago Island, Bolinao, Pangasinan using Sentinel-2A which is a multispectral imagery with 10, 20, and 60-meter spatial resolution and Landsat 8 that has two instruments which are the Operational Land Imager (OLI), and Thermal Infrared Sensor (TIRS). In order to classify benthic habitats, a fieldwork was done to gather validation points. With this, five (5) classes were considered which are algae, corals, deep water, sand, and seagrass. As a limitation to this study, land area, cloud cover, and turbid water were masked so it would not affect the classification. Image preprocessing involves radiometric calibration, atmospheric correction using Quick Atmospheric Correction (QUAC), and Lyzenga's water column correction. During the image processing, the supervised classification used were Maximum Likelihood Classification (MLC) and Support Vector Machine (SVM). After classification, error matrices were produced using similar region of interests for both images. An accuracy of 92.2242% for Maximum Likelihood Classification and 89.6022% for Support Vector Machine was obtained from Sentinel-2A. For Landsat 8, an accuracy of 78.5461% was achieved using Maximum Likelihood Classification and 86.3475% for Support Vector Machine.
