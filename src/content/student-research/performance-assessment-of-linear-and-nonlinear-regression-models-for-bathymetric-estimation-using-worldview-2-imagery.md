abstract: |-
  Bathymetric mapping can be done using multi-spectral imagery such as those taken by DigitalGlobe's WorldView-2 satellite through different methods of bathymetric extraction, as an alternative to hydrographic surveying and other traditional procedures. WorldView-2 is a commercial high resolution satellite, featuring 0.46 m panchromatic spatial resolution and 1.84 m multispectral resolution, with eight bands- coastal blue (400-450 nm), blue (450-510 nm), green (510-580 m), yellow (585-625 nm), red (630-690 nm), red edge (705-745 nm), near infrared 1 (770-895 nm), and near infrared 2 (860-900 m). It allows for the calculation of depths up to 20 m. The objectives of this study are to estimate bathymetry from a WorldView-2 image using regression models, and identify which of the created models has the best predictive capability in estimating water depth. The study area was the area west of Boracay Island, Philippines. In this research, two methods of bathymetric estimation were performed, namely: linear regression and nonlinear regression. The WorldView-2 image was preprocessed using FLAASH in ENVI to produce an atmospherically-correct and filtered image. The reflectance values processed by FLAASH in bands 1 to 5 (coastal blue, blue, green, yellow, and red) were matched with absolute depths of the evenly distributed, seventy (70) percent SBES survey test data, and the linear and non-linear models were determined through the use of statistical software XLSTAT. To analyze and improve the data, residuals between the actual depth and predicted depth were computed which showed certain trends that led to the succeeding steps. The points were classified according to bottom type, reef type, and depth, and the same procedures with the test data were performed. Then, the R² and RMSE values of all the regression models were compared and analyzed. Performance assessment was also done using the remaining thirty (30) percent SBES data validation points. The regression models of the classification, which were assessed to have the relatively best assessment parameters, were also evaluated by applying them to the entire World View-2 image and comparing the values with the depth measurement of a small strip of MBES data. The R² values of the linear regression models improved relative to the R² values using all the test points when separate regression models were created for each classification, particularly with the bottom type classification. Moreover, all of the R² values improved when nonlinear regression was performed, but there was no prevailing trend in the RMS values observed when the nonlinear regression models were applied to the validation data set. However, the linear models performed better when applied to the whole WorldView-2 image and checked with the MBES data. Ultimately, the best predictive capability in estimating water depths was observed using separate regression models for each bottom type as seen through both R² and RMSE values.
