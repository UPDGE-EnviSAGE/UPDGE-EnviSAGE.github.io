abstract: |-
  As the Asia's rising tiger in terms of economic growth, Philippines will now be a preferred investment destination. One of the maior causes of the nation's economic competitiveness is because of its robust infrastructure spending going up. As infrastructures serves as a tool for the nation's economy to function, their construction however may negatively affect the project if the scheduling is delayed and not followed. Thus, planning their construction will be the driving force to accomplish each project's task. Current practices of predicting the performance of construction of a building are still manual, time consuming, and error prone, as it may impose a tedious process of analysis of several data leading to delays that generates additional costings and effort. The main goal of this research is to develop a methodology for building construction progress monitoring that is based on (1) 3D as-built model of the building generated from unmanned aerial system (UAS) images using free and open-source software (FOSS) and photogrammetric techniques, (2) 4D as-planned schedule integrated modelling using blueprint of the building from computer-aided design (CAD) drawings, and data integration of as-built and as-planned models by (3) geographic information system (GIS) analysis. Monitoring was done by capturing videos of the building with a camera equipped UAS. Still images were extracted and filtered from these videos to generate the 3D as-built model using open source photogrammetric software. The as-planned model was derived from CAD drawings that was digitized and imported into a GIS environment using ArcGIS as a platform. Extrusion based on each building element's height, and integration of the construction planned schedule was done to form the 4D as-planned model of the building. The 3D as-built model was aligned against the 4D as-planned model of building. Points within the search radius of each building element in the as-planned model were determined.. The points were then evaluated using the parameters such as point cloud density and difference in centroid. Point cloud density are number of points that intersect with the building element per square meter area, while difference in centroid is the difference of centroid of both building element and points within the search radius. These parameters were then used to determine if the building element exist or not with applied threshold on varying building elements. The construction progress is then visualized via color-coding the building elements in the 3D model. The methodology developed for monitoring building construction progress was conducted and applied from the data obtained from an actual construction site. Accuracy in detecting built or not built building elements ranges from 82-84% and a precision of 50-72%. Quantified progress in terms of the number of building elements are 21.31% for November 2016, 26.84% for January 2017, and 44.19% for March 2017.The results from this methodology can be used as an input for improving decision-making process and progress monitoring performance of construction projects.
