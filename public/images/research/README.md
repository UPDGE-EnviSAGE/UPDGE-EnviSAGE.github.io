# Research Image Assets

This directory is reserved for optimized, public-approved EnviSAGE research visuals used by the website.

Intended future structure:

- `coastal/`
- `water-quality/`
- `habitats/`
- `terrain/`
- `environmental-monitoring/`
- `geoai/`
- `fieldwork/`

Do not place raw scientific datasets, unreviewed thesis materials, large rasters, or archival data exports here. Only optimized web derivatives with documented provenance, permission, captions, credits, and alt text should be committed.

Recommended filenames should be descriptive lowercase kebab-case, for example:

- `coastal-calatagan-sentinel-benthic-2025.webp`
- `water-quality-bolinao-chlorophyll-2026.webp`
- `habitat-palawan-mangrove-2025.webp`

Avoid names such as `final2.png`, `map_new_new.png`, or `figure6-revised.png`.
