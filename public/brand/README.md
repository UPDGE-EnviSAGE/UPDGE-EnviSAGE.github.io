# Brand Assets

This directory is reserved for approved EnviSAGE brand assets.

The existing historical EnviSAGE logo remains the temporary official logo and is stored here as:

- `envisage-logo-legacy.png`

This file may be used until the future modernization process is completed.

Do not redesign, redraw, trace, convert, recolor, crop, or otherwise modify the legacy logo. Do not fabricate replacement logo graphics.

Expected future assets may include:

- `envisage-logo.png` - future approved full logo
- `envisage-logo.svg` - future modernized full logo
- `envisage-mark.svg` - future simplified mark
- `envisage-logo-mono.svg` - future monochrome lockup

The design system must remain compatible with both the current legacy logo and future redesigned assets.
