# Brand Assets

This directory is reserved for approved EnviSAGE brand assets.

The existing historical EnviSAGE logo remains the temporary official logo, but no approved logo file is currently committed in this repository. Do not fabricate replacement logo graphics.

Expected future assets may include:

- `envisage-logo.png` - current approved historical logo
- `envisage-logo.svg` - future modernized full logo
- `envisage-mark.svg` - future simplified mark
- `envisage-logo-mono.svg` - future monochrome lockup

Until approved assets are provided, use the typographic lockups in the design system.
